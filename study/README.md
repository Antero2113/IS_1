# study/ — учебные копии исходников с комментариями

Эта папка содержит **копии всех JS-файлов проекта** с сохранённой структурой и
подробными комментариями на русском: что делает каждая функция, блок и строка,
а главное — **почему это сделано именно так** (с точки зрения безопасности).

## Как читать (рекомендуемый порядок)

1. [`server.js`](server.js) — точка входа: как всё собирается вместе.
2. [`src/config.js`](src/config.js) — откуда берутся настройки и секреты.
3. [`src/security.js`](src/security.js) — экранирование (XSS) и валидация ввода.
4. [`src/db.js`](src/db.js) — работа с SQLite, параметризованные запросы (SQLi).
5. [`src/auth.js`](src/auth.js) — JWT: подпись, проверка, middleware.
6. [`src/app.js`](src/app.js) — сборка приложения, порядок middleware, ошибки.
7. [`src/routes/authRoutes.js`](src/routes/authRoutes.js) — вход (bcrypt, rate-limit).
8. [`src/routes/dataRoutes.js`](src/routes/dataRoutes.js) — защищённые данные.
9. [`test/api.test.js`](test/api.test.js) — security-тесты (как проверяются защиты).
10. [`eslint.config.js`](eslint.config.js) — SAST-конфигурация.

## Важно

- Код в копиях **функционально идентичен** оригиналу (добавлены только комментарии),
  поэтому учебную версию можно запускать точно так же:
  ```bash
  npm test                     # запустит и test/, и study/test/
  node --test study/test/      # только тесты учебной копии
  npx eslint study/            # проверить аннотированные файлы линтером
  ```
- Вся подробная документация по API, запуску и CI/CD — в корневом [`README.md`](../README.md).
